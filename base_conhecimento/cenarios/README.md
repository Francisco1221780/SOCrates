# cenarios

Telemetria e respostas do analista usadas para testar e demonstrar a base, um ficheiro por cenário (`cenario_01.txt` … `cenario_34.txt`, mais variantes como `cenario_07b_sim.txt`).

- `indice.txt` dá a ordem e o que cada cenário testa. A ordem importa: os cenários contam uma história seguida.
- Nas variantes 7b e 19b usa-se só uma das respostas (`_sim`, `_nao`, `_nao_sei`); o 29c usa-se em vez do 29b.
- Os cenários 30 a 34 são atividade normal e não devem concluir nada.

Estado: os 67 ficheiros de cenário da v6 e o `indice.txt`.
